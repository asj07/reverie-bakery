How it works: These promos show in the scrolling strip below the main navigation on your homepage. Toggle a row ON to display it, OFF to hide it. You can use emojis and the ₹ symbol.

Note: Settings are stored in this browser (localStorage). For a shared admin that updates for all visitors, this would connect to a database (Supabase) — ask your developer to wire that when you're ready.
